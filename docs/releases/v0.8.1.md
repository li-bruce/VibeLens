# VibeLens v0.8.1

This patch makes the repository’s Windows watcher test tolerate a temporary file-sharing denial during atomic status replacement. It retains the original eight-second deadline, update predicates and all business assertions. Invalid content and permanent access failures remain errors.

Runtime and Skill payloads match [v0.8.0](v0.8.0.md) byte for byte. Its 2D/3D graph, source navigation, recording, databases and mapping checks are unchanged. Existing projects retain their runtime approvals and view configuration.

Install `skills/vibelens` from `v0.8.1` for this fixed repository version, or download the attached Skill ZIP. [Validation and the original failure](../review/release-v0.8.1/README.md).

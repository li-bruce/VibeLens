# VibeLens v0.9.0

Shared rules now form a single network connected to business actions, native predicate functions, parameters and recorded evaluations. Shared conditions retain their identities across operations and iterations. Strict protocol, mapping and runtime checks distinguish implementation coverage from business correctness.

The product introduction and interactive demo follow a file-sharing application: confirm its flow, record a failed revocation, trace the unchanged state and zero affected rows to source, ask AI to fix the argument, and retest. Five steps retain the key interactions, with saved view editing inside inspection. English and Chinese share the native 2D/3D viewer and original execution records. Graph-writing guidance removes generic authoring commentary while retaining business conditions and debugging facts.

This release also fixes nested control selections losing canonical ancestry and source panels closing on keyboard focus restoration. Existing predicates, source/build checks and regression expectations remain enforced. Controller regressions now use a frozen fixture so future marketing examples can change independently.

The independent native upgrade passed 35 tests, 84 scenario runs, 282 business assertions and ten negative evidence controls. Scoped view controls, source navigation, recording, 2D/3D and observer isolation passed. Failures, repairs, visible trial conversations and the assisted/unassisted cost comparison are retained in the [review](../review/file-sharing-demo/README.md). The comparison is one descriptive case and does not establish a token saving. Recording drain latency remains a documented optimization item.

Install the complete `skills/vibelens` folder from tag `v0.9.0`, or use the attached Skill ZIP. Start a project conversation with `$vibelens`. [Usage](../usage.en.md) · [Validation](../review/release-v0.9.0/README.md).

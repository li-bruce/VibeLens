## Install this test snapshot

```bash
git clone --branch feat/otel-provenance https://github.com/li-bruce/VibeLens.git
cd VibeLens
python tools/install_skill.py --project /path/to/your-project
```

The installer creates `.agents/skills/vibelens` in the target project and preserves an existing installation. Review an existing copy before replacing it. For Codex's Skill installer, specify repository `li-bruce/VibeLens`, ref `feat/otel-provenance`, and path `skills/vibelens`.

Open a conversation in the project and explicitly invoke `$vibelens`. A later request can be:

> I want to change how a shared file is withdrawn. Show the affected part of the existing business graph first and clarify any changed access rules before implementing it.

The agent maintains intermediate graph and observation artifacts. Manual viewer controls still use `/vibelens`. The final publication report supplies the exact commit ID for a reproducible installation.

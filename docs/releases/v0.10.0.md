# VibeLens v0.10.0

Explore nine connected layers, from the business flow you confirm to running
functions, project files and stored data.

- **Project structure:** scan directories, files, imports, dependencies and cycles;
  follow files into their code symbols. Refresh the index after source edits.
- **Clearer layouts:** stronger type clusters and shared initial 2D/3D coordinates,
  with saved positions and pins retained across iterations.
- **One reading order:** business, states, rules, API, core functions and values,
  data operations, project structure, code symbols, then data structure at the base.
  Custom layer orders and view filters stay saved.
- **Interactive introduction:** English/Chinese layer explanations with real 3D
  rotation, keyboard navigation and mobile support.

A real file-sharing application and a feature iteration exercise all nine layers,
actual values, state transitions, shared permissions, queries and source updates.
The review retains missing-mapping failures, fixes, recordings and screenshots.
The final source commit also passed the full GitHub check matrix, including live
database tests. [Validation](../review/release-v0.10.0/README.md).

Install the complete `skills/vibelens` folder from tag **v0.10.0**, or download
**vibelens-v0.10.0.zip** from this release. In a project conversation, start with
`$vibelens`. [Installation and usage](../usage.en.md).

## 中文

本版把九个观察层串联起来，从确认的业务流程，逐步看到运行函数、工程文件与数据存储。

- 新增工程结构层，自动扫描目录、文件、导入、依赖与循环，并连接到代码符号。
- 优化类型聚类，二维和三维共用初始坐标，保留手动位置与固定点。
- 统一默认层序，数据结构位于最底部；自定义排序、筛选与布局继续保留。
- 介绍页支持中英文、真实三维旋转、键盘操作与移动端查看。

验收使用真实文件共享程序及一次功能迭代，逐层核对状态、规则、实际数值、查询和源码更新，
并保留失败、修复、回放与截图。详见[验收材料](../review/release-v0.10.0/README.md)。

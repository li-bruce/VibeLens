# VibeLens v0.14.0

Follow business, state and rule networks through directional layouts, inspect
their definitions and source, and replay the same connections in 2D or 3D.

## Changes

- **Connected concept views.** ELK arranges flows, branches, joins and cycles.
  Separate conceptual roles retain explicit mappings to physical declarations.
- **Readable node details.** Inspect supported transitions, rule dependencies,
  business neighbors and source references. Optional AI explanations appear in
  the details panel, using the selected language and current graph revision.
- **Stable navigation.** Expansion, collapse and dragging preserve saved
  positions. View presets and manual layer selection stay aligned; hidden source
  calls no longer become direct business connections when regions are folded.
  Expanded-region titles remain visible and clickable above crossing links.
- **Consistent connections.** Same-type endpoints use solid profiles;
  different-type endpoints use dashed profiles. Single, double and bordered
  strokes identify relation families. Lines and moving arrows share layer colors
  in 2D and 3D, with neutral gray for cross-layer connections.
  Slow renderers retain visible arrow movement, and paused replay lets the
  current transfer reach its endpoint before repeating it.
- **Smaller application integration.** Native state execution and selected
  probes remain in the application; analysis, recording and the viewer run from
  the installed Skill. Native producers acknowledge capture scope and queue
  flushing through a bounded JSON control bridge.

Original node/relation identities, recorded facts and project business rules are
preserved. Existing projects use the managed runtime-upgrade and verification
workflow to adopt the new runtime and viewer.

## Install

- `vibelens-v0.14.0.zip`: complete Skill directory.
- `dsh-vibelens-0.14.0.tgz`: DeepSeek Harness plugin.
- `vibelens-skillhub-v0.14.0.zip`: complete Skill in the catalog transport format.
- `SHA256SUMS` and `manifest.json`: artifact and source-file checksums.

```sh
npx skills add li-bruce/VibeLens --skill vibelens
```

Invoke `$vibelens` in Codex or `/vibelens` in Harness. For a fixed version,
install the release archive. Harness compatibility remains **0.2.2-rc.1**, with
**Node.js 24.9+**; the observer requires **Python 3.11+**.

quality, clean exported examples and package parity. The included viewer evidence

retained. Live database-container suites run separately in GitHub Actions;

## 中文

本版让业务网、状态网和规则网的线路更清楚，并统一二维、三维的观察体验。

- 按流程方向布局，保留分叉、汇合和循环；展开、收起后保留手动位置。
- 节点详情显示状态转换、规则依赖和源码，可在面板内查看 AI 解释。
- 语义名称跟随界面语言，预设视图与图层选择同步。
- 同类型节点用实线，不同类型用虚线；单线、双线和描边区分关系类型。
  连线与流动箭头使用图层颜色，跨层连接统一为灰色。
- 修复低帧率时箭头停在起点的问题，暂停回放会完整播放当前步骤后循环。
- 修复连线经过展开区域标题时抢走双击操作的问题。
- 项目保留原生状态执行和必要探针，分析、录制与图工具由独立 Skill 提供。

下载上方完整安装包，或通过 Skills CLI 安装。已有项目按原有升级流程更新并验证。

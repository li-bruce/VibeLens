# VibeLens v0.12.1

This patch fixes two problems found while building a file-sharing application in
an independent conversation: source-free design graphs failed to open, and
expanded groups could extend beyond the viewport after arranging the graph.
Design previews now load from the project identity and Fit uses current visible
geometry. A browser regression covers business, state and rule views.

Repeated transition-effect assertions now share one displayed association, with
their original IDs and source evidence preserved for focus, filters and saved
views. State definitions, binding checks and runtime events remain unchanged.

The Skill checks native state-binding capabilities before confirming the design.
The current binding supports one primary state model; this patch does not add
multi-model execution. The browser CI job also installs its existing telemetry
test dependencies.

Install the complete `skills/vibelens` folder from **v0.12.1**, or extract
`vibelens-v0.12.1.zip`, then use `$vibelens` in the project conversation. Existing
project runtimes can use the managed upgrade workflow. See
[usage](../usage.en.md) and the [patch review](../review/release-v0.12.1/README.md).

The independent conversation is still in progress. Its preserved findings are
regression evidence; they are not a completed end-to-end trial.

## 中文

本版修复独立文件共享应用试用中发现的两个问题：尚无源码的设计图无法打开，
以及重新布局后展开区域超出视窗。现在可以正常查看业务、状态和规则草案，
“适应视图”按当前可见节点和区域重新计算范围。

同一状态转换与效果之间的重复声明现在共用一条显示关系，同时保留原始 ID、
来源、绑定要求和已保存的选择。状态定义及运行事件保持原有含义。

Skill 会在确认设计前说明原生状态绑定能力。当前仍支持一个主状态模型，
本版没有加入多状态模型执行。浏览器 CI 同时补齐已有的遥测测试依赖。

安装完整的 **v0.12.1** Skill 后，在项目对话中使用 `$vibelens`。
独立对话试用仍在进行中，结果及原始失败记录见本版检查材料。

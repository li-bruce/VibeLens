# VibeLens v0.13.0

VibeLens now ships as an explicitly invoked DeepSeek Harness plugin alongside the
Codex Skill. The package includes the complete observer, native adapters and Web
viewer. The tested Harness version is **0.2.2-rc.1** on Node.js 24.9+.

Animated transfers use directional arrows in both 2D and 3D, including return
paths. Nodes share a clearer visual vocabulary: routes for business operations,
branches for decisions, modules for functions and layered cylinders for storage.
Layer colors, stable identities, saved views and recorded facts are preserved.

The product homepage and illustrated English/Chinese READMEs explain modeling,
inspection and iteration. The interactive demo retains its separate file-sharing
story. The Web tool's development focus is desktop interaction.

## Downloads

- `vibelens-v0.13.0.zip`: complete Skill folder.
- `dsh-vibelens-0.13.0.tgz`: prebuilt Harness plugin.
- `vibelens-skillhub-v0.13.0.zip`: self-contained SkillHub transport. Its local
  Python bootstrap verifies and extracts all bundled resources; no download is
  needed. This meets SkillHub's 200-file limit without dropping modules.
- `SHA256SUMS` and `manifest.json`: artifact and canonical-file checksums.

Use `$vibelens` in Codex or `/vibelens` in Harness. Existing projects retain the
managed runtime upgrade and verification workflow.

# VibeLens v0.11.3

Paused Timeline inspection keeps the selected causal connector moving even when
the current Graph has no transfer edges. The selection remains on the same
recorded event, with its original timestamps and lifecycle.

Browser reload checks now wait for the actual saved visibility, scope and height.
The earlier failure, its controlled reproduction and the retests remain in the
[release review](../review/release-v0.11.3/README.md).

This release includes the project-owned source boundaries from v0.11.2: initial
directory planning, advisory Git ignore inputs, dependency/output pruning before
descent and consistent source, API, project-tree and mapping checks.

The independent project passed its business, mapping, lifecycle and isolated
viewer checks. An earlier shared-default layout change remains unattributed;
the review retains that preservation failure separately. The later isolated
conversation-view measurement left the default unchanged and captured zero
business events from observer controls.

Install `skills/vibelens` from **v0.11.3**, or use the release ZIP, then invoke
`$vibelens` in the project chat. See [installation](../usage.en.md).

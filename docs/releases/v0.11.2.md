# VibeLens v0.11.2

This patch makes source ownership consistent across the file tree, code and API
graphs. Observer configuration and recording directories share one default
artifact classification. An explicitly declared local source file or subtree is
restored in every view, with its real file owner and API endpoints.

The initial project plan records owned modules, dependencies and generated
storage. Git ignore rules remain advisory; ignored first-party code is still
checked. Changes during development use the same scope and strict mapping gates.

Timeline browser tests now zoom to actual call intervals in stages. SQLite
fixture storage and temporary journals are classified before recording starts.
Original lifecycle, event-count, hover and exact-event selection checks remain.

The native state engines and business rules are unchanged. See the
[patch review](../review/release-v0.11.2/README.md) for retained failures,
regressions, managed upgrades and the independent dialogue.

Install `skills/vibelens` from **v0.11.2**, or use its release ZIP, then invoke
`$vibelens` in your project chat. See [installation and usage](../usage.en.md).

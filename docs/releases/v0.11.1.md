# VibeLens v0.11.1

This patch follows the graph, API, source-documentation and Timeline changes in
[v0.11.0](v0.11.0.md).

- Keep concurrent invocations in separate Timeline bands when a coarse clock
  gives them identical timestamps and ordered producer witnesses prove overlap.
  Measured timestamps, durations and original events remain unchanged.
- Render legacy committed/transformed data lifecycles without projection errors;
  keep Graph and Timeline cursors aligned and retain neutral closed-state styles.
- Establish owned-source and output directories with the initial project plan.
  Skip dependencies and declared generated artifacts before traversing them;
  use the same boundary in source analysis and the project-structure view.
- Keep Git ignore rules as tracked scope inputs, discover new owned source and
  reject application mappings into pruned directories. Existing exclusions still
  undergo the original hidden-implementation checks.
- Preserve Unicode formatter output on Windows legacy consoles, including
  actual tool failure exits. Run pinned browser tests on supported Ubuntu 24.04.

The [repair review](../review/graph-quality-20261104/README.md) retains the first
local pass, subsequent CI failures, fixes and distinct retests. The
[patch review](../review/release-v0.11.1/README.md) records publication and the
fresh GitHub-installed dialogue separately.

Install the complete `skills/vibelens` directory from **v0.11.1**, or download
**vibelens-v0.11.1.zip** from its release. Invoke `$vibelens` in your project chat.
See [installation and usage](../usage.en.md).

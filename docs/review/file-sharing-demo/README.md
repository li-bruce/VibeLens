## Retained product failures

1. The state-only presentation hid a containing node and its states. The presentation now expands required ancestors before narrowing the view.
2. Native playback matched data dependencies only to data edges. Real Boolean child results therefore failed to animate their logical guard edges. The canonical viewer now requires an explicit child-event dependency and matching evaluation/build basis for this case; skipped and cross-evaluation negatives are tested.
3. The page telemetry still referenced an obsolete decision field after migrating the artifact. It now uses the actual inspection node, so the displayed state and affected-row values come from the selected event.
4. A source file contained mixed newline bytes. Export checks validate the original archive bytes against the manifest and separately compare decoded, newline-normalized text with the captured source. The raw-byte hash requirement remains intact.

Original failure screenshots and completed receipts are retained under `checks/`. The browser suite checks English/Chinese, mobile, 2D/3D controls, recorded motion, backward seek, source highlighting, full application captures, saved filters across builds and reload, and reduced motion. The seven-step predecessor passed the complete bilingual browser test. The final five-step presentation passed both languages, five-node source focus, 17-node saved views across builds/reload, eight native presets/layers, actual motion, source and mobile/reduced-motion checks. Unit/source checks and runnable-core tests remain separate from browser acceptance. The independent frozen framework round passed; its [public derivative index](trials/frozen-repeat/native-3052/index.md) and [original/public hashes](trials/frozen-repeat/native-3052/public-export.json) preserve private-session masking. See [the plan](PLAN.md) for failures and retests.

This is an automated, simulated-user trial. It is not a human usability study or a statistically controlled token-efficiency experiment. The cost report records framework repair separately and reports the observed higher assisted cost rather than claiming a saving.

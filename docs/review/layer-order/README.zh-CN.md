# 图层顺序调整

介绍页、实际工具和示例统一采用以下默认顺序：

**业务 → 状态 → 规则 → API → 核心函数与值 → 数据处理 → 工程结构 → 代码功能 → 数据结构**

先看业务与行为模型，再看入口、函数和数据处理，继续查看工程与代码细节，底部展示数据的存储结构。
状态和规则共同描述业务，这个顺序用于阅读，不代表程序执行顺序。工程结构展示目录、
文件与依赖；代码功能继续展开文件中的声明、调用和参数。

旧版默认层序会迁移，自定义层序保留。拖动或键盘调整会明确记为自定义顺序。
隐藏项、位置、固定点、批注和自定义视图保留。画布上的层列表与键盘操作顺序一致。

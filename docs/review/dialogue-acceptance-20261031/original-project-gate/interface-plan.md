# Interface design

The primary task is moving a private file through selected review to revocable access. The workspace keeps owned files and received files in the main column; the review queue and private message center stay visible in the right column.

Tokens: deep ink `#173537`, muted text `#607477`, cool paper `#f3f7f8`, white surfaces `#ffffff`, teal actions `#087f83`, quiet lines `#dbe5e7`. Display typography uses Segoe UI Variable Display, body uses Segoe UI / Microsoft YaHei, and account/data labels use Consolas. All have local fallbacks.

The signature is the folded file mark and a small owner → reviewer → recipient route on the sign-in screen. It explains the actual sharing relationship. The working screen avoids decorative diagrams and uses ordinary forms, readable states, explicit permission messages and anchored navigation. Layout collapses naturally below tablet widths; focus remains visible and no animation is required.

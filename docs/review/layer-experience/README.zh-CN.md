## 测试项目

随后新增“所有者重命名文件”，测试私有和已共享两种状态，并验证接收者无权修改、空名称被拒绝。

新增代码但未补图时，维护扫描检出了两个未映射方法。测试工具复现编码阶段的同步步骤，
补齐业务、状态、权限、参数和埋点映射，再执行检查。源码结构与数据映射通过现有模块自动刷新。
这次是实现和运行验收，没有重新开展一次独立的人机对话研究。

## 布局修复

演示页原先覆盖了默认聚类算法；跨组节点也会集中到同一边缘位置，再被避让计算挤散。
现在区分稀疏和密集的外部联系，保留组内排布并扩大组间距离。
同一组 90 节点的回归中，落到其他类型中心附近的节点从 9 个降为 0。

新建 3D 视图沿用已知的 2D 平面坐标，已有手工位置和固定节点继续保留。
实际浏览器测试核对了坐标、拖动、类型分组和固定位置；4,000 节点布局在独立线程完成，页面事件循环持续响应。
布局耗时与渲染帧率分别看待，原始数据见 [布局验收](layout/browser.json)。
